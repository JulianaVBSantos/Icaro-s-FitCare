# Ícaro's FitCare

Aplicativo mobile voltado ao acompanhamento de alunos durante a prática de exercícios físicos, com foco em pessoas que apresentam necessidades específicas, como limitações decorrentes de lesões, condições físicas ou períodos de recuperação.

## Sobre o projeto

O **Ícaro's FitCare** é uma solução desenvolvida através de um projeto extensionista para auxiliar o profissional de Educação Física no acompanhamento individualizado de seus alunos.

A proposta é centralizar informações relevantes sobre cada aluno e facilitar o planejamento e o acompanhamento dos treinamentos, permitindo considerar características, restrições, observações e registros relacionados à evolução durante o processo de acompanhamento.

O aplicativo busca contribuir para um atendimento mais organizado e personalizado, auxiliando o profissional na tomada de decisões relacionadas ao acompanhamento dos alunos.

## Objetivo

Desenvolver uma solução mobile que facilite o gerenciamento das informações dos alunos e o acompanhamento de seus treinamentos, especialmente daqueles que possuem necessidades específicas ou estão em processo de recuperação física.

## Público-alvo

* Profissionais de Educação Física;
* Alunos acompanhados pelo profissional;
* Pessoas que necessitam de um acompanhamento de exercícios adaptado às suas condições e limitações.

## Principais funcionalidades previstas

Entre as funcionalidades previstas para o aplicativo estão:

* Cadastro e gerenciamento de alunos;
* Registro de informações e observações sobre os alunos;
* Registro de condições e restrições físicas;
* Acompanhamento de treinamentos;
* Registro de relatos de dor e ocorrências;
* Histórico de acompanhamento;
* Organização das informações para auxiliar o profissional durante os atendimentos.

As funcionalidades poderão ser ajustadas conforme o levantamento de requisitos e a evolução do projeto durante as sprints.

## Tecnologias

O Ícaro's FitCare será desenvolvido como um aplicativo mobile para a plataforma Android, utilizando Android Studio como ambiente de desenvolvimento. A interface da aplicação será planejada e prototipada no Figma, enquanto o GitHub será utilizado para versionamento e acompanhamento da evolução do projeto.


## Desenvolvimento

O projeto será desenvolvido de forma incremental, organizado em quatro sprints. O repositório Git será utilizado para acompanhar as alterações realizadas e registrar a evolução dos artefatos técnicos ao longo do desenvolvimento.
